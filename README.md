Este repositorio contiene la implementación de una API RESTful y WebSocket en tiempo real desarrollada en Python con FastAPI y Programación Orientada a Objetos (POO). El sistema está diseñado para el control, monitoreo e historial de movimientos de un vehículo IoT (Montacargas), desplegado en una instancia Amazon EC2 (Windows Server 2025) y conectado a una base de datos relacional administrada en Amazon RDS (MySQL).
